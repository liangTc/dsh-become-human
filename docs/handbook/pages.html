试一次读取与确认写入

  1. 下载 React 计数器示例（.tgz），通过 Human 的「插件 → 安装与管理」安装。
  2. 打开「交互页面示例」，记下当前数字。点「增加一次」再取消，刷新后应保持原数值。
  3. 再次增加并确认，值应只增加一。关闭页面再打开，确认读取的是同一份计数。这个例子只写插件自己的计数文件。

const result = await human.call('counter.read');

让清单与后台方法一致

包清单中的 nodeId 指向本包节点；client 对应已打包文件。每个 methods 条目都要提供 name、mode、description。后台按相同页面 ID 注册同名 handler，模式为 read 或 write。统一合同可在 pages: [{id, handlers}] 中注册；计数器演示的是兼容入口 ctx.humanPages.register(owner, pageId, handlers)。

handler 的第二个参数含 sessionId、requestId 和 signal。验证输入及取消信号，用 requestId 关联幂等写入。确认票据绑定本次会话、方法和完整参数，有效期 60 秒。接口超时后，先读取业务结果；外部写入状态未知时交给用户核对。

单个页面最多声明 24 个方法，客户端最大 1 MiB，单次 JSON 输入和输出各限 32 KiB。后台最多同时处理八个调用，超时为十秒。扩展前端与宿主同源，后台以本机权限运行，只安装信任的代码。凭据留在后台。页面与 RPC 合同
