做一个「节拍观察」插件。启用一分钟后，它提供一次行动机会。Human 选择记录时，你可以在日志里找到对应的任务回执。

先运行示例

  1. 准备已完成初始化的 Human 测试人物。本手册以 0.7.0-beta.45 为基线；自行打包需要 Node.js 24+ 和 npm。
  2. 下载节拍观察安装包（.tgz）。进入 Human → 插件 → 安装与管理，选择文件，核对包名 dsh-human-pulse-example，勾选信任并点「安装并应用」。
  3. 在已安装列表中打开「节拍观察」。看到说明和当前人物状态，就已验证页面与节点。若节点被停用，先在该插件详情中启用。
  4. 若要观察行动，确保测试人物的自主活动已开启，当前处于允许的时段，有可用额度。定时到期后先查看日志中的定时触发记录，再看随后一轮选择和任务结果。只有被选中且完成时才会出现「已记录一次节拍」。示例的执行代码本身不调用模型；宿主选题仍可能消耗额度。

理解包里的三个文件

package.json
name 是注册时使用的 owner。dsh.bundle.patch 指向安装清单；dsh.human.plugin.version 声明生命周期合同版本。静态页在 dsh.human.pages 中声明。
cordis.patch.yml
将包添加为运行节点。页面的 nodeId 必须与此处的 id 一致。包改名时同时修改节点名、清单引用和后台 owner。
index.mjs
Cordis 注入 humanPlugins，apply(ctx) 注册资源。在 effect 的清理函数里调用 dispose()，停用插件时撤销注册。

改一行，再打包

克隆源码后，打开示例的 index.mjs，把 execute 返回的 summary 改成自己的文案。给自己的版本设置新包名或递增版本号，然后在示例目录执行打包。可以先用 --dry-run 检查文件清单。

git clone https://github.com/liangTc/dsh-become-human.git
cd dsh-become-human/docs/examples/human-pulse-example
npm pack --ignore-scripts --dry-run
npm pack --ignore-scripts

将生成的 .tgz 安装到测试人物。相同定义的一次性计划会记住完成状态；要从头验证，使用新的测试人物，或为独立的新计划更换定时 ID。打开示例源码
