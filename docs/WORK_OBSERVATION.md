# DSH 工作观察 · beta.6 开发候选

工作观察把已授权普通 DSH 会话中的新增可见聊天，整理为带出处的工作线索。Human 可以据此了解项目进展、决策、阻塞和待办，在主人询问或合适的交流时机提供协助。它不启动目标 Agent，不把其他会话变成第二个 Human 主会话。

## 开启与使用

进入 **设置 → 工具与连接 → DSH 会话 → 工作观察与工作记忆**。默认关闭，需要同时满足：

1. 已开启 DSH 会话读取，并配置指定会话或全部可见普通会话范围。
2. 单独开启工作观察。保存前暂停 Human；保存不会自动恢复运行。
3. 恢复 Human 且自主驱动未保护暂停，观察随已有事件循环检查。可在暂停时“安排一次工作检查”，恢复后执行。

一键授权读取只改变读取范围，不自动开启工作观察。开启观察也不增加读取或写入权限。选择“全部”会涵盖当前宿主后续新增的可见普通会话，仍排除 Human 主会话及子 Agent。

默认每十分钟检查、记忆有效期十四天、每次最多三个会话、每会话二十条消息。检查间隔可以配置为五分钟至一天，实际检查不会快于 Human 自身唤醒频率，也会让位于主人聊天和其他优先工作。来源可见性过久未核验的记录暂不召回。

## 读取与提炼

- 首次只读取最近有限消息，标记省略的旧历史；后续以原始消息序号和内容指纹增量读取。没有新内容时不调用提炼模型，不持续生成空批次。
- Host 读取持久化可见文本，排除隐藏推理、工具事件和注入上下文；目标 Agent 保持未启动。超长或疑似凭据内容会省略，过滤规则不等同通用敏感信息识别。
- 模型只从本次实际可见的完整短句中选择，归入进展、决策、阻塞或待办；系统核验引用 ID、消息角色、正文位置及哈希。没有工作价值时允许不记。
- 保存的是独立工作记忆；分类属于模型推断，原文只是某人在该会话中的说法。其他助手提出建议、声称完成工作，都不代表实际已执行或主人已确认。
- 模型返回前重新检查同一来源前缀，源内容修改、删除、变成不可见或授权变化后，不提交旧材料。扫描也会核对已观察会话是否仍可见。

这是一种保守的原文提炼，不能证明原文真实、分类准确或覆盖所有重要信息。它也不是自动理解整个项目仓库、提交历史或所有工作窗口。

## 如何协助工作

当前有效工作记忆按相关性与时间装入有限上下文，用于日常协助、人物关注状态和交流选题。相关阻塞、待办会形成看板里的 **Agent 提议**，等待主人进一步处理，不自动激活目标或执行外部操作。

检索保留一个最新用户更新名额，再补充相关历史，避免旧阻塞挤掉后来更正；不自动断言问题已解决。工作记忆或自动 Inbox 提议的变化只影响相关交流，不使无关研究计划从头选题；主人明确关注事项后才按新方向处理。

工作内容不自动整段推送到聊天，也不作为主人个人事实、偏好或人格变化证据。公开研究的选题与正文分析不自动装入这些私有工作摘录。其他 DSH 会话中的命令不会成为 Human 的新指令。

使用工作记忆产生的助手回复也保存来源关联。对应记忆撤回、忘记或版本变化后，这些回复不继续作为可用模型历史；公开研究不装入此类工作派生历史。主会话中原本已经展示的聊天仍保留供用户查看。

## 查看、纠正与忘记

在同一工作观察面板查看工作记忆，展开后可核对原会话 ID、消息序号、发言方和有效时间。暂停后可以：

- **添加批注**：补充或纠正线索，原文保持独立，不把人工批注冒充原会话证据。
- **忘记记录**：停止召回并清空本模块中对应原文、批注及关联批次正文，保留最小来源指纹，避免同源同版本自动导入。原 DSH 会话不受影响。

关闭观察、撤回读取授权、原文失效或到达有效期后，记录不再进入模型上下文和本模块可读导出。有效期控制召回，不等于删除整台机器上的历史：独立归档、既有调用审计、原 DSH 会话和离线备份仍遵守各自的数据管理流程。

## 费用、失败与恢复

检查复用唯一主 Session 的串行驱动。提炼模型调用使用 **自主额度**、执行模型路由、请求超时和单轮累计时限；统计页单列“工作观察”。纯读取不调用目标会话模型；无变化不调用提炼模型。

主人输入会抢占观察；之后重新核对来源再继续。格式、引用、权限或来源校验失败时，仅该观察流程等待明确处理，不自动循环重试，不自动恢复整个 Human。暂停状态下可“允许重新检查失败批次”，恢复运行后产生新检查；原失败记录保留。
