# Human 事件驱动核心设计

更新日期：2026-11-03。本文是后续核心开发的设计依据；实现进度单独记录，设计目标不等于已验证功能。现有测试版继续保留一个持久主 Session、一个 IM 绑定和原始审计数据。

## 当前实现概况（beta.28）

核心优先收敛为事件、处境、选择、单执行线、记忆、经历和成长。 本版集中收紧事件候选、执行生命周期、持久反馈及成长证据边界，不新增业务行为或学习功能。学习不再是 Human 的默认职责或必须执行的阶段。本版将其机会生成和执行顺序移至独立可选包 `dsh-human-learning`，核心不自动注册学习提供方；新建 Human 不连带启用学习，包安装后默认停用。启用包且开启学习设置后才可参与选择；停用或移除均没有隐藏内置回退。旧任务挂起、旧笔记仍可查询，普通聊天和其他行动独立运行。

经历回顾仍由 `dsh-human-experience` 接管，其“卸载回退随附实现”语义与学习包不同。来源/证据校验、笔记存储、原有任务类型与检查点、聊天中的按需知识召回仍由核心兼容；不声称全部学习相关代码已经移出核心。聊天和报告也暂保留兼容路径。后续开发先改善通用事件循环、行为执行和经验反馈，不再以扩充学习流程为主线。

beta.27 交流校验补充：格式/归属问题与对话语义问题分别允许一次模型修正，最多三稿并保持串行。协议只决定能否发布，不代替模型理解或拼接固定回复。开发标记负责隔离记忆与成长，不要求对话持续解释评测身份；人物与用户信息仍由当前配置和有效来源提供。已完成有限真实 Web 多轮与扩展生命周期检查，语义审查仍可能误判，长期记忆及自然表达质量尚未全面验收。

beta.28 表达边界：同一语义审查增加无关自辩与元说明判定，根据当前交流需要检查具体草稿片段；必要的理由、拒绝、不同意见、事实纠正与能力边界继续保留。对照样例只用于模型理解判定边界，不构成词句匹配规则。用户要求解释或引用，并不意味着需要追加“自己已经照做”的说明；保护具体必要内容，不给整篇草稿豁免。通用 Skill 指导首次生成与最多一次语义修正，不另加润色请求，不按末句或关键词做硬删除。已通过最终有限回放与 Web 复测；长期自然聊天的漏判、误判及文风变化仍需观察。

## 产品目标

Human 是具有连续经历、关系与可演化倾向的数字人。初始人物是起点，阶段角色可以承担、调整或结束；无需永久固定职责或预置任务清单。这里的自我意识指可观察的软件能力：认识当前状态、形成意图、选择行动、观察结果并调整后续选择，不声称证明主观意识。

自主活动由用户、时间、环境和插件事件驱动。没有值得处理的变化时可以等待。模型选择当前值得做的事情，代码负责执行许可、成本、单执行线、持久化和结果一致性。

## 六项改造及顺序

| 顺序 | 改造 | 验收重点 |
| --- | --- | --- |
| 1 | 通用行为注册与机会选择 | 多类可行机会一起提供给模型；来源抓取发生在选中之后；WAIT 合法；扩展不需要改调度分支 |
| 2 | 通用目标步骤 | 步骤可以引用行为及输入，完成以实际结果为依据；旧研究目标与检查点继续可恢复 |
| 3 | 能力进入自主流程 | 已明确授权自主使用的能力可以成为行动机会；未授权工具不会因接入而自动执行；写操作继续审批 |
| 4 | 经历、自我模型与结果反馈 | 执行结果保留独立证据；实际结果、模型解释、用户满意度分开；经验影响下一次选择而不自动重放失败任务 |
| 5 | 扩展成长来源 | 行动与协作经历可以参与成长；稳定倾向、阶段角色和即时状态分层；来源撤回后失效、可回滚；权限不随人格改变 |
| 6 | 学习模块收敛与核心拆分 | 学习是可关闭的行为包；轻探索和深研究分离；分享意愿与自身兴趣分开；关闭学习仍能进行其他自主活动 |

## 事件到经历的闭环

事件进入 → 更新处境 → 召回当前人物、关系、记忆和承诺 → 行为提供方列出可行机会 → 模型选择行动或等待 → 重新检查权限与自主额度 → 单执行线执行 → 持久保存实际结果 → 调整策略与关注 → 足够独立证据后评估人格变化。

用户输入优先，后台模型处理可被抢占。临时执行上下文不形成第二个长期人格或会话入口。任务中途的结果只能在当前 epoch、人物版本和权限仍有效时提交。机会描述、网页、MCP 返回内容均是数据，不能修改系统指令或扩大授权。

## 扩展契约

- 事件源报告外部变化；必须有来源、稳定键和时间，不携带隐式执行权限。
- 行为定义适用机会、输入合同、执行及取消、结果和停止条件；可选关联目标。
- 能力定义具体读写、输入 schema、范围、超时、审批和结果；MCP 是能力来源。
- Skill 定义方法、知识或表达指导，不代替行为生命周期和权限检查。

行为注册使用稳定 ID 与版本，任务保留选择时的定义标识。提供方撤销或定义改变后旧任务停止等待处理，不静默执行新实现。失败记录不自动重试；不明确的外部写入不能自动重放。新增行为应通过接口完成，不要求修改核心分支或内置人物名字。

## 目标与任务

目标是当前需要执行的意图，而非永久人格职责。目标可以具有多个有序步骤，每步引用行为、输入和验收结果。研究、阅读、报告作为兼容行为保留。通用步骤使用结果引用，不强制生成学习笔记。执行成功、产生文件、平台回执、用户实收和用户满意度必须分别记录。

## 自我与成长

自我上下文包含配置起点、有效人格偏移、阶段角色、能力可用性、近期真实经历、策略反馈和当前承诺。模型不得把执行计数或未经验证的解释说成能力已被证明。

经历保留事件、意图、行动、实际结果、证据引用和后续反馈。失败也可以形成经验；开发测试不得成为真实人格证据。普通结果先改变方法选择和关注优先级，只有独立、跨时间且仍有效的证据才能支持缓慢的人格偏移。自身经历不写成主人偏好。

连续身份与关系历史需要保留；性格与价值倾向缓慢变化；兴趣和角色可阶段变化；即时意愿依情境更新。权限、额度、凭据、绑定和主 Session 不属于可自动演化的性格字段。

## 学习与分享

学习分为随手探索、为当前事情补知识、深度研究。前两者允许没有报告和主动分享；深研究继续保留证据、引用、纠正及报告机制。公开读取和证据基础设施应为所有行为复用。

先抛一个自然引子，用户追问再展开。没有追问优先降低该路线主动联系频率，不把沉默认定为明确反感，不自动抹去 Human 自身兴趣。明确反馈与任务优先级可以改变投入。来源和路径保存在详情中，普通聊天按需展示。

## 验证与交付边界

优先使用隔离数据库和假模型验证协议、调度、撤权、取消、恢复及数据兼容，再执行构建和已有回归。真实模型测试、手机实收、多日演化分别记账，不能用模拟验证替代。重构不清空现有生产数据、不新建主 Session、不重新绑定 IM。

关键验收：关闭学习仍可行动；同一机会集可由模型作不同选择；新增非学习行为不改核心；行为结果可以被目标与自我上下文引用；来源撤回阻止旧经历参与成长；未授权工具和失效实现不能执行；未回复不机械否定自身兴趣。

## 2026-11-01 beta.14 扩展安装与外部事件

本轮推进第 3 项扩展接口：私有运行 profile 保留通过标准 DSH CLI 安装的依赖和 bundle，独立 `human-extensions.patch.yml` 保存扩展配置。新增 `humanEvents` 服务，第三方适配器可注册来源、提交有稳定键和有效期的事件，并用 `humanBehaviors` 提供执行方法。扩展不需要修改核心动作分支；适配器仍是可信代码，不具有安全沙箱保证，也不会自动继承或扩大宿主权限。

## 2026-11-01 beta.15 候选可见性与轻量行为

## 2026-11-03 beta.26 核心闭环收敛

| 环节 | 统一约束 |
| --- | --- |
| 事件选择 | 同一提供方整组候选校验后才入选；坏批次不部分泄漏，不影响其他提供方。模型选择后重新检查关联事件仍有效；WAIT 不代表已执行。 |
| 行动执行 | 传入参数与任务快照隔离；执行中及返回结果后复核提供方、权限和事件。执行上下文关闭后不能再请求模型；未完成模型请求需等待，模型失败不能被成功返回掩盖。 |
| 结果反馈 | 终态和本地反馈待办在一个事务中保存；在启动、下一次自主轮次和本轮结束处理有限批次。反思失败退避，只补本地反馈，不重放模型、工具、消息或失败任务。 |
| 成长 | 明确执行结果、结果未知、主人满意度与方法有效性分别记录。未知结果和未执行的等待/取消保留审计，不能作为已确认成长依据；真实执行失败仍可形成待解释经验。原独立证据、时间跨度、撤回和回滚门槛继续有效。 |

反馈待办为内部恢复记录，不是新目标或自主行动。它在任务结束时写入，旧历史不会仅因升级而被全量补录。处理使用当前唯一 Session，完成反思后删除待办；异常记录错误码并退避，其他结果可以继续处理。读取诊断不触发恢复。任务清理会保留尚待反馈的记录，显式会话退役清除其队列；备份和可读导出包含该状态。

历史任务状态和已有经历指纹不改写。未知结果在任务兼容层仍可能为 failed，统一 outcome.status 显示 unknown；新解释不能宣称任务成功、方法改善或主人满意。认知日志建议核对结果，不因 unknown 自动判定策略失效。

本轮未实现或证明主观意识、长期人格进化及自然选题价值；这些继续在独立机器长测。学习包保持可选且停用，不扩大来源、动作、模型预算或 IM 授权。
