## 结构

![像素风架构：Web 与 IM 通过管理插件连接独立运行模块、主会话与统一能力接口](assets/architecture-pixel.svg)

安装在宿主的 bundle 只插入 `become-human-manager`，不替换普通 DSH 的 Agent 工厂。管理插件启动独立进程与私有 profile；默认工具禁用、持久化与额度边界位于内部运行模块。进程隔离降低相互影响，但不等于不可信代码沙箱。

## 一条主线

Human 保持一个持久主 Session。定时唤醒、聊天、学习、提醒与工具任务共享调度边界。主人输入优先，后台任务通过取消信号及 epoch 检查停止或挂起；只有符合当前状态的结果才能提交。

轻量协调阶段选择一个问题或等待，执行阶段使用临时任务上下文处理有限工作。它不是永远不停输出的模型内心独白。外部 DSH 会话保持独立，仅通过明确授权的读取或写入操作访问；向其发任务可能产生额外模型调用。

## 上下文与证据

上下文按阶段组装：

1. 当前人物与关系是统一身份来源。
2. 当前状况包含有效任务、最近联系、等待原因与授权状态。
3. 根据问题召回有限记忆、近期事件概览、学习笔记与目标摘要。
4. 选择、执行和主人对话使用不同的输入预算，保留当前输入及必要证据。

事实、推断、主人原话和 Agent 学习笔记有不同来源标识。修订、撤回、过期和开发测试数据会影响其可用性；来源摘录不当作完整语义总结。详细公开资料分析会减少不必要的主人私人上下文。

选择下一步的顺序是：**当前人物配置 → 有效记忆、反馈与目标 → 模型选题**。文本 Skill 补充方法与表达，不能成为隐藏人物覆盖或绕过权限的入口。

### 人格偏移层 · beta.5 开发中

`persona-development.mjs` 在基础人物之外保存可撤回的兴趣、性格倾向和习惯。开关默认关闭，旧 `verbosity` / `humor` 自动微调授权不迁移；手动表达模式与旧表达微调不再参与新的人格控制。基础身份、关系、职责、工具权限及模型路由不会被偏移写入。

开启后由原执行线安排每日回顾，不新增 Session、进程或模型 runner。每条偏移至少要求 3 个独立来源根、24 小时的证据跨度及最低置信度，变化幅度受到限制；重复引用不会持续累加成新证据。记录当前结果、观察提案、前后值、原因及来源指纹；来源撤回、过期或修订后重新核验，失效结果退出上下文。主人可单条撤回，关闭开关保留历史但停止注入。

这些记录是 Agent 自身倾向的模型推断，不写为主人事实，也不保证真实心理或语义成立。回顾请求计入自主用量，由现有取消与 epoch 检查处理抢占，不能靠页面刷新发起额外模型调用。

### 记忆生命周期层 · beta.5 开发中

`memory-lifecycle.mjs` 将冷热等级、固定状态、使用信息与重复关系保存为原记忆之外的覆盖层。按时间与合格新增数量安排规则维护及必要的摘要，默认 24 小时 / 30 条、7 天热 / 30 天冷。身份、事实、目标、工作记忆以及仍关联有效目标的记忆受保护；分层改变召回优先级，不物理删除原始来源。

只有合格情景记忆参与模型摘要，批次保存原记忆版本与来源指纹。摘要独立存储，标为 `derived-model-summary` / `inferred` / `unverified-model-inference`；来源与逐字摘录检查只提供结构支持，不证明摘要所有结论都被语义支持。原记录保留，修订或遗忘使旧摘要失效，冷层可按问题相关性召回。

恢复批次撤下对应摘要，并恢复仍有效、未被后续操作改动的原覆盖层；不会复活已撤回的证据。摘要与人格回顾都通过原自主调度及额度路径执行，主人输入可抢占。长期精简质量、遗忘与召回表现需要真实持续观察，不以功能存在或模拟时钟认定通过。

## 任务看板与认知记录 · beta.5 开发中

任务看板集中展示自主任务、目标与子步骤、定时任务、工具作业和文件产物，并收纳关注事项、自我状态与结果反思。默认显示摘要，可展开单个节点或本页全部节点。`cognition.mjs` 保存事项、单一关注、方向摘要、规则反思及版本记录；`cognition-runtime.mjs` 将它接入原选择、执行、取消和结果流程，`cognition-dialogue.mjs` 提供有界的前台看板读写。Web 与 Agent 使用同一数据源，不创建第二个 Session、独立人格、后台进程或模型 runner，原有效 IM 绑定不变。

- **自我状态**：从当前人物、驱动状态、能力配置、已有任务和有效来源重建，不把能力启用视为实时探测成功。
- **持久事项**：保留为什么做、预期结果、下一步、停止条件与复查时机；主人配置、Agent 提案与运行事实区分来源。
- **注意力管理**：先检查主人优先、暂停、错误、预算与已有任务，再结合重要程度、等待和到期情况整理候选。用户设置关注只记录意图，不恢复驱动。
- **有限执行映射**：研究、问题类事项可以进入原公开学习流程；交流借用原闲聊机会及退避规则。目标、承诺等类别不会仅因创建卡片自动获得执行路径或确认。
- **结果反思**：按任务状态、尝试、有效笔记与本地发布记录形成规则摘要和待确认建议。反思不自动重试、修改人格、扩权限或补额；主人事项不能由 Agent 静默改写。

有限事项与反思摘要按阶段预算参与上下文，详细公共资料分析继续减少私人上下文。看板读取本身不调用模型；原模型回合仍承担选择和执行成本。停止条件是说明性的任务契约，不是可执行脚本，也不能保证任意自然语言条件都能自动准确判断。

看板与时间线均只展示可观察的意图、依据和结果摘要，不暴露原始 chain of thought。执行完成、本地消息发布、平台发送成功、手机实收、主人满意度是不同证据层级。已验证片段与完整验收的区别见 [测试状态与待测清单](TESTING_STATUS.md)，认知记录的边界见 [看板说明](CHARACTER_BOARD.md)。

## 统一能力接口

能力描述包含名称、版本、参数 schema、读写效果、范围、超时、结果大小、取消方式及是否允许自主调用。任务持久化保存实际输入和定义快照。

- 读取仍受资源白名单约束，结果作为不可信外部资料交给模型。
- 写入先准备预览，批准绑定任务、参数摘要、能力定义和权限版本。
- 超时、取消或断开后，无法确定外部结果的写入变为 `unknown`，不自动重放。
- 同一执行门控制前台、后台与桥接操作，取消不会提前放行尚未真正结束的外部动作。

内置 MCP 是真实 stdio JSON-RPC 连接，提供公开网页读取服务。`beta.5` 可自行配置外部 stdio / Streamable HTTP MCP，发现工具后逐项授权；MCP 服务器本体和依赖仍需自行安装，不提供任意服务器的一键安装器。DSH 桥接直接使用宿主服务读取会话，可授权全部可见普通会话并收回；写操作仍逐笔审批。浏览器桥接使用受限 CDP 操作，不提供任意 JavaScript 执行；DOM 点击也不等同系统可信鼠标事件。

代码已预留可信提供方注册接口，但第三方插件与代码 Skill 不能当作安全沙箱中的扩展。当前也没有完成自主选题器对任意注册能力的通用规划。

## 源码目录

```text
plugins/
  become-human/          # 运行模块源码：调度、记忆、学习、额度与能力
    cognition*.mjs      # beta.5 开发中：共用事项、自我状态、注意力与反思
    persona-development.mjs # 有依据、可撤回的人格偏移记录
    memory-lifecycle.mjs    # 记忆冷热覆盖层、摘要批次与恢复
  become-human-web/      # 对外分发的 DSH bundle
    manager.mjs         # 宿主服务、Web 与 IM 入口
    supervisor.mjs      # 私有运行进程生命周期与桥接
    source-models.mjs   # 读取宿主官方模型目录和原生 DeepSeek 配置
    source-credentials.mjs # 按来源优先级解析凭据，仅在进程内传递
    worker.mjs          # 使用管理器传入的凭据环境启动运行模块
    native-*.tsx        # Human 工作区组件
    host-capabilities.mjs
    browser-capabilities.mjs
    im/                 # 来自 dsh-im 并按唯一会话改造的渠道代码
    runtime/            # build 生成的运行源码副本
    runtime-bundle/     # build 生成的内部 DSH bundle
plugins/become-human/presets/  # 人物与自主额度预设
docs/                   # 使用、架构、发布说明与图片
```

`runtime/` 与 `runtime-bundle/` 由构建同步，不应绕过上游 `become-human/` 单独修改。开发验证目录、运行数据、凭据和历史设计文档不属于公开分发内容。

## 开发与构建边界

在仓库根目录安装开发依赖并构建，主构建会重建 IM 的 host 与客户端、生成 Human Web 客户端并同步内部运行模块。定时规则文件随仓库提供。

```powershell
npm install --prefix plugins/become-human-web
npm run build --prefix plugins/become-human-web
npm run release:package
```

修改日历生成逻辑时，先执行 `npm run build:schedule --prefix plugins/become-human-web`，再执行主构建。`npm run release:source` 另行导出干净源码，以脚本输出路径为准；这两项准备操作不会自动发布。

IM 构建读取本包开发依赖；日历规则来自精确版本的 `@deepseek-ai/dsh-schedule`。重新生成时保留来源信息、上游许可证与修改说明。开发机的缓存目录和私人路径不属于构建契约。第三方代码清单及授权关系见仓库的许可证和第三方声明文件。

## 当前交付边界

- 完整运行依赖 Windows DPAPI；跨平台与跨机密钥迁移未完成。
- 兼容性固定 DSH `0.2.0-rc.2`；不能推定兼容未来 rc 或 Desktop。
- 一个 Human 绑定一个 IM，更换会替换旧绑定；12 种聊天适配与 Office 连接器存在不等于每个平台已完成真实验收。
- 开源发行排除 WhatsApp 及其 GPL 依赖链与 QQ 的未授权扫码连接器；QQ 使用手动 AppID / AppSecret。
- 浏览器需要用户自行配置本机 CDP 与范围，不会自动启用或接管浏览器。
- 公开搜索会受站点限制和证据质量影响；没有充分资料时应保留失败或等待状态。
- 行为时间线是可追溯摘要，角色状态是规则与记录推导，不代表真实意识或情绪。
- 长期运行、跨日、故障恢复与长期人格反馈需真实时间验证，不以隔离场景或经过时间替代。
