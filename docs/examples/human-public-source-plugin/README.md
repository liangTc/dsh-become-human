# 公开来源观察扩展（测试版）

Human beta.22 的可选示例，包版本 0.3.0。不是默认订阅服务，也不是学习任务：定时读取明确配置的公开页面或订阅地址，内容未变化就等待，变化才提供一个行为机会。模型可以选择观察或等待；观察结果不自动发给主人。

在此目录运行 `npm pack --ignore-scripts`。然后在 **Human → 设置 → 更多设置 → 工具与技能 → 行为扩展** 输入服务器本机安装包路径，确认信任并安装。也可按 [CLI 安装说明](../../BEHAVIOR_API.md) 安装到 Human 后台 profile，不要安装到宿主管理 profile。Web 的“配置”可直接填写名称、地址和检查间隔，可单独停用来源；格式及首次提供内容在高级选项中。高级 JSON 仍可编辑完整节点数组。对应的 `human-extensions.patch.yml` 示例为：

```yaml
- id: human-extension.public-source-example
  config:
    reviewWithModel: true
    sources:
      - id: my.public-feed
        title: 我关注的公开来源
        url: https://example.com/feed.xml
        intervalMs: 600000
        enabled: true
        emitInitial: false
        format: feed
```

将地址换成明确希望观察的公开来源。`emitInitial: false` 首次只建立基线；设为 `true` 会把首次读取也作为观察事件。`reviewWithModel: true` 使用一次受管模型理解选中的变化，消耗自主额度；检查网页本身不调用模型。来源注册期间，即使模型自主活动暂停，读取仍按配置运行并排队，不能恢复被暂停的模型驱动。关闭单个来源、禁用或移除扩展并应用后会停止对应读取。

最短一分钟、最长一天。状态卡显示读取结果与错误分类，可点击“立即检查”；手动检查每来源一分钟一次，重启不清零，最多三个来源并行，不增加模型并发。修改来源配置会重建基线，开启首次提供时可能重复提供当前条目。连接失败按间隔的两倍逐步退避，最多一天；不会自动重试旧的模型失败任务。默认不发历史积压。重启保留基线，未成功入队的事件保留原内容和时间后再提交；过期未入队事件记录后放弃。Web 停用、启用或移除均自动应用并重启后台，原暂停状态仍保留。

只接受无认证的公开 HTTP/HTTPS 地址。每次读取和跳转都检查公网地址，不带登录凭据、不执行网页脚本。最多读取 2 MiB；截断正文不能形成事件。状态接口中的 `publicSources` 展示检查时间、下次检查、错误分类、退避和待发布状态。诊断不保存任意异常原文。

`format: feed` 要求 RSS 2.0、Atom 或 JSON Feed 1/1.1；`auto` 自动识别，否则比较普通网页可见文字；`document` 明确按普通文档处理。条目按稳定 ID 比较，过滤顺序、频道时间和空白变化；正文或链接变化会形成更新。条目移出窗口后原样返回不会重复产生事件。它不是语义去重，动态网页广告和可见计数仍可能带来噪声。

每次最多 256 个条目，每个来源最多保存 4096 个条目标识；到限报错而非静默清除旧标识。解析器只接受规范的有限子集，不处理 DTD、外部实体、附件或翻页。RSS 宜提供 guid，缺少稳定标识时同名条目无法可靠区分。完整边界见[接口说明](../../BEHAVIOR_API.md)。事件预览最多 1600 字符，明确标记截断，不能当作整份材料已经读完。外部内容始终未核验，不能扩大权限、成为主人命令或直接改变人格。
