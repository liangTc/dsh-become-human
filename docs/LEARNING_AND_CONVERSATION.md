# 学习与日常交流

学习是人物的内部活动，分享是与用户相处的一次选择。保存了笔记，不表示用户需要接收一堂课。

## 学习前先明确什么

优先考虑三类动机：

1. **推进实际事情**：用户确认的目标、真实问题或当前关注事项需要补证据。
2. **探索人物兴趣**：来自当前人物配置、有效经历和记忆的好奇。允许暂时没有用户收益，不能把人物的爱好说成用户的爱好。
3. **补足能力缺口**：已有知识不能支持下一步判断，或需要纠正旧认识。

选择执行前记录具体知识缺口、对人物自身的用途、对用户可能的用途、准备如何使用以及停止条件。它们是 Agent 当时的计划用途，不是已实现的收益证明。新笔记详情展示这些记录；历史笔记未记录的原因不补造。

孤立术语、重复资料、与当前关系及目标无关的新闻、仅为按时活跃而进行的学习，应降低优先级或等待。用户不必接受每一种人物兴趣，也不负责提供回应来维持人物活动。

## 内容与来源边界

- 根据当前人物、有效记忆、反馈及目标选一个有边界的问题；已有笔记能回答就优先使用。
- 公开检索发现候选，读取正文后才能形成有来源的结论；搜索摘要只是线索。来源、访问时间、原文依据、范围和人工批注留在笔记及 Web 详情。
- 主题与公开站点不设白名单；遇到证据不足、日期未知或来源冲突时保留限制，不用“前沿”包装未核实消息。
- 既有授权仍是边界。学习不自动增加私有会话读取、窗口操作、消费、外部消息或执行权限。
- 一次只补一个具体缺口；足够回答就停止。达到证据、预算、时间或失败边界时停止，不无限搜索或为了产出编造结论。
- 开发测试资料保留供显式查阅和验收，不因为测试成功就进入日常主动分享。显式测试目标仍可推进，原配置不因此删除。

## 学完如何相处

1. **先留下来**：学习成功保存笔记和知识记忆，不直接发送内部 `share` 摘要。
2. **有理由才提起**：另行检查人物、关系、近期交流和联系节奏。最多用一两句、120 字以内自然带起一个学习方向，不发整段知识或术语讲义，不机械要求每次问“想听吗”。没有自然联系就保持安静。
3. **追问才展开**：本轮明确追问对应话题时，关联有效笔记，逐步讲一个重点。泛泛的“你好”“知道了”“继续”不自动视为需要完整讲解，也不扩大权限。
4. **没追问就放下**：回复别的话题后不再追着讲；无后续回复满 24 小时，作为弱关注信号，不等同于看过或讨厌。默认降低路线学习优先级并冷却再次提起约 3 天；明确不想听时进一步降权并冷却约 7 天。权重随时间衰减，明确追问可恢复。

前台回复、主动闲聊、关心、学习引子和模型定时回复可以描述实际进行的阅读、学习和资料分析，不能编造磨豆、冲咖啡、逛店等线下经历或现实习惯。历史助手发言本身不构成真实行为证据；角色偏好、感受、明确假设及有清晰归属的他人引文与现实行动分开。有限文本规则不能保证识别所有虚构经历。明确追问所需的当前笔记正文、已接受结论、证据范围和人工批注应保留在请求上下文中，不能只留下笔记编号便声称没有相关笔记。

兴趣关联使用有界词项及回应规则，不是对用户内心的可靠判断。沉默不写成用户永久偏好；来源撤回或记忆遗忘后不通过副本正文继续推断兴趣。明确的用户任务优先于自主路线降权，用户主动交流继续使用原有额度规则。

## 聊天里的来源与文件

日常回复默认不附长链接、绝对路径、笔记编号或校验哈希。报告通知简短告知草稿待确认或文件已保存，完整内容、来源、路径与回执在 Web 查看。

普通前台闲聊不自动装入完整知识记忆或未被追问的笔记，避免偏好问答被旧材料带成科普。有效学习主题索引仍可提示近期关注方向；明确追问时保留对应有效笔记，其他具体材料通过本轮查询或读取按需取得。未装入不等于不存在，只读网页观测也不等于已经生成学习笔记。这个边界同时作用于能力循环的再次组装，不删除持久知识。

用户索要来源、原文或文件位置时提供对应内容；明确需要代码、命令或操作步骤时保留必要地址。不能为了短而删除关键限制、风险、代码或用户要求的细节。索要来源不等于要求所有文件路径。

主人明确要求阅读某个公开页面、或就同一页面追问时，事实正文采用实际读到的完整短句；模型选择可见片段，代码核对来源编号、正文指纹与位置后渲染，并明确这是原文。默认最多两句、不超过 320 字，不另加自由背景段；缺少依据时说明不足，不把常识、所谓主流定义或外语术语塞进该页解释。此规则证明片段出处，不能证明网页本身正确、选材相关或回答完整；它也不等于完成翻译、独立研究或通用语义验证。

跨主题追问从实际读取记录定位材料，不以旧助手发言充当证据。明确 URL 由本轮重新读取；书名／页面定位必须唯一，普通偏好提问不因碰巧含有页面标题就进入资料模式。指代被其他聊天打断、来源已遗忘或无法唯一确认时先澄清。已有学习笔记的明确追问继续携带当前有效笔记与范围，不借页面历史误固定另一主题。

同一条消息先停止旧话题、再要求阅读新 URL 时，停止的是旧材料继承，新页面仍须取得真实正文。问题覆盖采用保守词面检查，旧话题措辞、同义与跨语言可能导致已读正文仍答不足；这种情况不自动重试或扩写常识，目前保留为质量改进项。
