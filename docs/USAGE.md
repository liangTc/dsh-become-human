## 工作区入口

进入 DSH Web 左侧的 Human 入口。Human 使用一个持久主会话，Web 与已绑定手机共享消息、记忆和任务状态。临时工作上下文可用于有限任务，结果统一回到该 Human；外部 DSH 会话作为被授权的资料或执行目标，不成为第二个人格入口。

新安装首次进入时，先按 **选择已有模型 → 人物与额度 → 创建并启动** 完成向导。内部目录、profile 和端口自动准备；“同时开启自主学习和主动交流”默认关闭，手机绑定可稍后进行。已配置的 Human 直接进入原会话，不会重新套用人物和额度预设。更多安装细节见 [首次设置](INSTALLATION.md#4-启动并完成首次设置)。

`beta.5` 测试包可选择 **DSH 原生 DeepSeek API Key** 或兼容的第三方模型，列表会标明来源。Human 通过宿主中的凭据引用解析密钥，不需要重复填写；若宿主尚未配置 API，请先到 DSH 模型设置完成，再返回点击“重新检查”。选择和创建过程不额外测试模型；DeepSeek 账号登录通道尚未接入。公开发行包与开发候选按各自版本分别验收。

10月28日的 beta.6 开发候选已在同机独立空目录完成真实官方模型发现、宿主进程凭据复用、后台启动与 Flash 请求，共享依赖缓存；不追记为 beta.5 已验收。最终发行包无缓存安装与更多凭据组合仍在[合并清单 D1/D2](TESTING_STATUS.md#merged-testing)。看到模型列表或“凭据就绪”本身仍不代表供应商已接受请求。

### beta.6 本地新版导航

| 页面 | 用途 |
| --- | --- |
| 对话 | 聊天、连续输入合并、图片与分条回复 |
| 任务 | 看板、目标、定时任务、工具作业、报告与审批、额外额度授权 |
| 资料 | 记忆库、工作记忆、学习笔记、长期话题、人物成长与整理结果 |

首次使用通常只需要四项：**人物与关系、自主行为、模型与对话、手机连接**。记忆整理、工具与 Skills、数据与安全收在“更多设置”；也可搜索名称直接定位。人物和额度预设先载入草稿，点击保存才生效。运行中保存会先暂停，保存后保持暂停，由用户在右上角恢复；不会静默重启自主活动或重试失败任务。

查看记录不必进入设置：关系和人格偏移结果在 **资料 → 人物成长**；工作摘录及批注在 **资料 → 工作记忆**；上下文装配、观察进度和恢复操作在 **日志 → 运行诊断**；发送窗口与待确认回执在 **日志 → 手机投递**。公开 beta.5 仍使用旧导航。

## 建立人物与相处方式

在 **设置 → 人物与关系** 从预设开始，或自己填写名字、角色、核心人格、兴趣和长期方向。关系定义应写清：希望怎样称呼、什么时候打扰、生活与工作各占多少、哪些话题不想主动谈。

例如工作助理可以写“关注我的项目进度，优先提出有证据的改进建议”；陪伴角色可以写“先听我说，日常回复简短，不催促我回复”。人物兴趣不等于主人的偏好，学习内容也不会直接变成主人事实。

### 协商与改变主意 · beta.6 开发候选

人物不必对所有普通请求立即答应。它可以说明暂时不愿意、提出替代办法，或在你补充理由、改变方式、友好示好后重新考虑；好感高也不保证同意。**资料 → 人物成长**可以查看当前好感、亲密、信任和最近的选择依据，不需要在日常聊天中报分数。

### 发送图片 · beta.6 开发候选

在对话框选择PNG、JPEG或WebP，核对预览后发送，可以配文字或只发图片。发送前可移除，失败会保留草稿并说明原因。聊天模型需支持图片；能力未知或仅文字模型不会假装看过。首版继续看图时需重新附图，语音和视频后续接入。规格与附件存储说明见[图片输入配置](CONFIGURATION.md#图片输入--beta6-开发候选)。

### 连续聊天与滚动摘要 · beta.6 开发候选

模型设置中已移除 Human 单次输出、请求总超时及输入字节预算，沿用 DSH 宿主模型默认值。累计开销仅在“自主行为”配置；近期对话、记忆候选和摘要仍按各自检索范围工作。旧预算失败留下的暂停不会自动解除，核对状态后可手动恢复自主，旧失败任务仍保留。

姓名和相处方式沿用当前人物配置，临时称呼可在聊天里说明；不会因为曾用过某个人物模板而固定成旧角色。通用 `human-dialogue` Skill 指导模型理解说话者、接住更正及自然回应，可在技能页启停或复制定制；没有固定人物台词，普通聊天也不强制产生关系分数。

近期上下文按完整问答带入，移出窗口的对话在主人聊天时按需整理成带来源的滚动摘要，另保留少量待压缩原文衔接追问。原文不删除，摘要有容量和覆盖边界，不保证无限历史逐字回忆。

在 **日志 → 运行诊断 → 上下文与记忆装配** 查看摘要版本、覆盖轮数、积压及实际带入情况；在 **统计 → 会话压缩** 查看额外模型开销。压缩属于主人沟通处理，不占自主额度池，但仍产生供应商费用。失败后聊天继续，先暂停并确认空闲，再按页面入口明确允许重新整理；不会因此自动恢复自主驱动。详见[滚动会话摘要配置](CONFIGURATION.md#滚动会话摘要)。

### 查看逐渐形成的人格倾向 · beta.5

在 **设置 → 人物与关系 → 关系与成长** 明确开启，默认关闭。原来的表达长短/幽默自动微调和手动“表达模式”已移除，旧授权不转移为新开关。

开启后按正常自主调度回顾真实交流与有效学习，逐渐形成 Agent 自身的兴趣、性格倾向和习惯。当前结果直接展示，历史默认收起；展开一条可看变化原因、前后值及原始依据，也可在暂停且空闲时单条撤回。证据不足会继续观察；关闭后结果保留但不再用于人格上下文。基础身份、关系、职责和权限仍由主人配置。

回顾最多每天一次，每项生效变化需要至少 3 个独立来源根、跨越 24 小时的经历及其他校验。变化是有证据关联的模型推断，不能仅凭一次回顾或角色化对话认定真实长期人格已经形成。模型请求使用自主额度，主人聊天可以抢占。详见 [人格偏移配置](CONFIGURATION.md#人格偏移--beta5-开发中)。

## 启动自主运行

1. 在 **自主行为** 开启所需的学习、主动联系或闲聊能力。
2. 设置检查间隔、静默时段与额度；建议先选低档。
3. 核对当前无待处理错误，再明确恢复运行。
4. 在日志页查看本轮选择与执行结果，在资料页查看笔记和记忆。

系统按事件循环判断是否值得做事，可以等待。每次唤醒不一定调用模型，更不保证每次向手机发消息。用户聊天优先于后台工作；后台工作被中断后保留任务状态，失败任务不会未经明确操作自动重试。

“24 小时在线”表示程序持续运行时具备响应与自主检查能力。电脑休眠、进程退出、模型服务故障或 IM 平台限制都会影响可用性，无法用累计经过时间证明持续在线。

## 任务看板 · beta.5

**任务看板** 汇总自主任务、目标与步骤、定时任务、工具作业和文件产物。先通过类型、状态、关键词与时间找到任务，卡片默认显示关键状态及结果摘要。点击单个节点展开，或选择本页全部展开/收起；分页之外的记录不会因为“全部展开”自动加载。刷新当前页会保留已展开节点的阅读状态。

进入看板中的 **关注事项、自我状态、决策与反思** 查看共用事项与认知记录。用户和 Agent 共用当前唯一会话中的持久记录；新增看板不另启后台进程或模型 runner，既有 IM 绑定继续使用。

事项先进入待梳理。填写“为什么关注、预期结果、停止条件、下一步”后，可加入关注候选。手动设置当前关注不会启动驱动；复查时间不是提醒。研究或问题类事项只能进入原有限学习路径，交流仍受主动联系与未回复退避规则约束；目标、承诺入卡不等于自动执行或完成。

前台对话接入有限看板读写，但 Agent 不能静默改写主人事项。反思根据任务、笔记与本地发布记录给出规则建议；采纳只更改事项，不增加权限或重试失败任务。本地发布、渠道 `sent`、手机实收和主人认可需要分别核对。详细操作与边界见[关注事项与反思](CHARACTER_BOARD.md)。

## 手机连接

在 **设置 → 手机连接** 选择渠道，完成该平台账户配置，再生成本人配对码并在机器人私聊发送。不要把凭据或配对码发到项目 issue。Human 只接受当前绑定本人的私聊，一个 Human 同时绑定一个有效渠道；更换会替换旧绑定。

开源版有 12 种聊天渠道实现与 Office 连接器，各平台所需账户、权限、网络条件不同。微信有实机验证记录，其他渠道不应仅因显示在列表中就认定在所有平台可用；iMessage 所需的 macOS 能力与当前 Windows 运行时不兼容，待后续平台适配。WhatsApp 与其 GPL 依赖链不包含在开源发行中；QQ 的未授权扫码连接器也已排除，改用手动 AppID / AppSecret。

### 微信同步与发送状态

微信的“消息同步在线”表示接收消息的长轮询正常；发送是否被平台接受会单独显示。页面根据最近一次已绑定本人从微信发来的有效消息，推算 24 小时参考窗口与剩余时间。该时间仅为估算，不能保证平台接受发送；缺少历史时间记录时显示未知，不从启动时间补算。网页聊天、自主唤醒和后台重启不会刷新这个窗口。

出现发送失败或平台 `-2` 回执时，页面会保留发送受限或失败信息；`-2` 本身不能确定是窗口、额度、内容还是其他平台限制。可从已绑定微信发送一条新消息，再核对更新后的状态与新消息的真实回执。旧的 `unknown` 投递仍需人工核对，不会自动补发；平台接受也不等于本人已读。

已绑定本人的图片或文件消息也会更新该次真实入站的发送上下文。**公开 beta.5** 仍以文字作为思考输入：附件会得到暂不支持进入思考的提示，不会自动下载、识别图片或读取文件。**beta.6 开发候选**已接入图片合同，但微信图片下载、解密、同一会话识别和手机实收仍待真实验收；Web 单张图片短测不代表微信端已通过，文件、语音和视频也不据此获得支持。

常用命令：

| 命令 | 作用 |
| --- | --- |
| `/help` | 查看当前手机命令 |
| `/status` | 查看唯一会话与运行状态 |
| `/pause` | 暂停运行；手机回复开关保持原设置 |
| `/resume` | 恢复运行许可；不会替代手机回复开关 |
| `/steer 内容` | 显式插话，进入较高优先级的输入通道 |
| `/reminders` | 查看提醒 |
| `/cancel-reminder 编号` | 取消指定提醒 |
| `/goals` / `/goal 编号` | 查看目标及详情 |
| `/goal confirm\|pause\|cancel\|retry 编号` | 确认、暂停、取消或明确重试目标 |

也可以用自然语言提出提醒，如“10 分钟后提醒我休息”。时间不明确时应先完成澄清。`/new`、`/session`、`/clear` 等创建或切换会话命令在本 Human 入口禁用，删除数据应在 Web 明确预览和确认。

## 目标、学习与实际产物

- **目标**：提出目标后，核对步骤、来源要求和验收标准。用状态及成果证据判断推进程度，不把“已提出计划”视为完成。
- **学习**：在记忆与学习中查看笔记、原始来源和有效性，可反馈、修订或删除。示例、条件与不确定性需随结论保留；自动校验只能拦截部分范围丢失、数字或引语错误，不能证明任意结论语义正确。自然对话默认不附一串引用；需要来源时直接要求。
- **人工批注**：修订笔记会保留独立批注、版本和时间，供后续回忆、分享与报告使用。批注不会覆盖网页原文，也不会自动成为已核实的外部事实；有分歧时应核对原始结论和批注。
- **摘要范围**：新笔记摘要和知识记忆概览只取已接受的完整结论，放不下时省略整条，完整结论仍保留在笔记中。用途、追问与自然分享是 Agent 的叙述，不是额外来源证据。
- **报告与文件**：先预览完整内容与目标路径，再批准写入受管产物目录。新报告单独收录人工批注；待执行草稿的批注变化后，需重新生成、预览并批准。已经保存的报告保留原文件，后续批注更新会提示重新生成。通过文件回执判断成功，取消或 `unknown` 不自动继续写。
- **定时任务**：创建一次性或周期任务，核对时区、触发时间与动作。暂停期间任务如何处理可在任务状态查看；不要把重复周期与一次性提醒混用。

### 查看与恢复记忆整理 · beta.5

进入 **设置 → 记忆与学习 → 记忆整理**，先看热、温、冷记忆数量及最近整理状态。默认每 24 小时或每新增 30 条合格情景记忆安排检查，热记忆参考范围 7 天、低频冷记忆起点 30 天；周期和条数可在高级设置修改。身份、事实与目标等重要记忆受到保护，归档保留原文，相关冷记忆仍可按需召回。

展开一个整理批次，可读摘要、核对对应原记忆与来源摘录。摘要属于未验证语义的模型归纳，不能直接当作主人确认事实。需要撤销整理时，先暂停并等待空闲，再选择“恢复此批原记忆”；失效或后来修改的原记录不会被强行恢复。关闭定期整理会停止新的维护，已有分层和摘要仍保留。整理与聊天共用唯一执行线，不另启后台思考进程。

人格偏移与记忆整理页都显示共享的经历回顾状态。等待额度时先核对预算；被聊天抢占时保留进度。若回顾失败或服务在执行中退出，先暂停、等待空闲并处理页面草稿，再点 **允许重新安排回顾**。此操作只记录许可，仍保持暂停；手动恢复后才重新核对来源并按自主额度安排执行，不会立即调用模型。

## 使用 MCP 与外部 DSH 资料

在 **任务看板 → 工具与能力** 选择已启用工具，填写 schema 要求的参数，提交后查看任务结果。内置 MCP 用于读取公开网页。调用结果是外部资料，内容不能改写人格、权限或向本系统下指令。

自定义 MCP：在 **设置 → 工具与连接 → 添加 MCP 服务** 填写 stdio 程序或 Streamable HTTP 端点，暂停后发现工具，逐项选择权限并保存。新服务和工具默认关闭；密钥使用专用环境变量引用，不直接填写在配置中。当前自定义工具由用户发起，不自动加入自主任务。

DSH 会话可一键授权读取或使用全部可见普通会话，也可展开配置只授权指定 ID。一键操作先暂停 Human 并保存，完成后手动恢复；发送任务和取消操作仍须逐笔批准。全部范围包含后续新增普通会话，排除 Human 主会话与子 Agent。会话正文按可见聊天筛选，结果可能分页或截断，应核对返回标记；列表为空不表示磁盘中绝无其他历史。详细设置见 [工具范围](CONFIGURATION.md#工具范围)。

普通对话也可触发已启用的有限工具调用。写操作只生成待审批任务，聊天中的“同意”不会绕过界面的精确预览批准。当前自主学习循环与通用工具调用是两个接入路径，尚未实现让自主选题器任意调用所有注册工具。

通过对话要求整理报告时，Human 会先按本轮主题查找已保存的有效笔记，再提出报告草稿。只读网页工具的结果不会自动变成学习笔记；缺少对应笔记时需要先完成学习。自动选材有有限的词面检查，批准前仍应核对主题、材料编号和完整原文。取消尚未执行的报告工具任务会同时取消其关联草稿；已执行或结果未知时，需要核对实际结果，不能以取消代替。

## 查看发生了什么

活动中的时间线用于回答：何时选了什么方向、执行了哪个任务、形成了哪些产物、写入或修订了什么记忆。事件日志提供更细的状态与错误码，可关联到任务。

时间线与任务看板都默认展示简洁摘要；单个节点可展开查看来源与关联任务，也可展开本页全部节点。更多筛选默认收起，需要排查问题时再按类型、状态、任务或时间缩小范围。

这些是**行为摘要与可追溯事件**，不展示模型私有的完整思维过程，也不能证明意识、真实情绪或长期人格进化。真实人格变化要有持续反馈及证据，不能用角色化说话方式替代验证。

## 使用注意

- 本地保存不等于所有处理都离线：模型请求会发送必要上下文，搜索会发送查询，手机消息经过对应 IM 平台。
- 自主额度控制本地准入，不是供应商硬消费上限；查看实际供应商账单，并保留保守用量与报告 token 的差别。
- `unknown` 表示结果不确定，不是确定失败。先查目标平台、文件或会话，避免重复发送和重复动作。
- 不公开认证 URL、凭据、数据库、聊天原文或未脱敏截图。发现问题可先暂停自主，再保存脱敏错误信息。

## 查看用量统计

在 Human 顶部打开“统计”：默认显示近滚动 24 小时，可切换到当前自主额度周期。该周期的主统计包含同一时间范围内的主人沟通和自主工作，展开的“自主额度”卡片只显示自主池。

- 总览分别显示供应商已报告 token、本地已分发模型请求、保守占额、待确认用量；保守占额不是额外账单，不能与已报告 token 相加。
- 小时趋势可切换 token 与请求次数。工作类别中，选题和执行沿用同一任务归属，目标任务优先计入“目标推进”，共享一次调用的记忆整理与人格回顾不重复拆分计费。
- 展开工作类别或模型查看输入、输出、缓存和失败/取消/等待明细；未提供的分项明确标为缺失。准备后撤回不算已分发请求，失败或取消不代表免费。
- 页面可见时每 30 秒更新，也可手动刷新。读取失败会保留上次数据并标记过期。查看统计仅读取已有请求与额度账本，不调用模型。
- 此页只覆盖本 Human 保留的模型记录。外部搜索、工具调用、订阅费和其他 DSH 会话消耗不在此模型统计中；历史记录删除后无法完整重建类别。
