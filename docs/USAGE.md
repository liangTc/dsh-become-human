# 使用指南

[返回首页](../README.md) · [安装](INSTALLATION.md) · [配置](CONFIGURATION.md)

> **测试版本 `0.7.0-beta.1` · 尚未开发完成。** 先使用独立数据目录和有限资源；本指南不表示每个平台均已完成验收。

## 工作区入口

进入 DSH Web 左侧的 Human 入口。Human 使用一个持久主会话，Web 与已绑定手机共享消息、记忆和任务状态。临时工作上下文可用于有限任务，结果统一回到该 Human；外部 DSH 会话作为被授权的资料或执行目标，不成为第二个人格入口。

| 页面 | 用途 |
| --- | --- |
| 对话 | 主人聊天、连续输入合并、短回复与分条展示 |
| 活动 | 查看直观时间线与事件日志，并按时间、类型、关联任务等筛选 |
| 任务 | 管理目标、定时任务、报告与文件、工具调用 |
| 设置 | 人格、手机、自主额度、记忆、Skill、模型、工具范围及数据维护 |

## 建立人物与相处方式

在 **设置 → 人格与关系** 从预设开始，或自己填写名字、角色、核心人格、兴趣和长期方向。关系定义应写清：希望怎样称呼、什么时候打扰、生活与工作各占多少、哪些话题不想主动谈。

例如工作助理可以写“关注我的项目进度，优先提出有证据的改进建议”；陪伴角色可以写“先听我说，日常回复简短，不催促我回复”。人物兴趣不等于主人的偏好，学习内容也不会直接变成主人事实。

## 启动自主运行

1. 在 **自主行为** 开启所需的学习、主动联系或闲聊能力。
2. 设置检查间隔、静默时段与额度；建议先选低档。
3. 核对当前无待处理错误，再明确恢复运行。
4. 在活动页查看本轮选择、执行结果、笔记与等待原因。

系统按事件循环判断是否值得做事，可以等待。每次唤醒不一定调用模型，更不保证每次向手机发消息。用户聊天优先于后台工作；后台工作被中断后保留任务状态，失败任务不会未经明确操作自动重试。

“24 小时在线”表示程序持续运行时具备响应与自主检查能力。电脑休眠、进程退出、模型服务故障或 IM 平台限制都会影响可用性，无法用累计经过时间证明持续在线。

## 手机连接

在 **设置 → 手机连接** 选择渠道，完成该平台账户配置，再生成本人配对码并在机器人私聊发送。不要把凭据或配对码发到项目 issue。Human 只接受当前绑定本人的私聊，一个 Human 同时绑定一个有效渠道；更换会替换旧绑定。

开源版有 12 种聊天渠道实现与 Office 连接器，各平台所需账户、权限、网络条件不同。微信有实机验证记录，其他渠道不应仅因显示在列表中就认定在所有平台可用；iMessage 所需的 macOS 能力与当前 Windows 运行时不兼容，待后续平台适配。WhatsApp 与其 GPL 依赖链不包含在开源发行中；QQ 的未授权扫码连接器也已排除，改用手动 AppID / AppSecret。

常用命令：

| 命令 | 作用 |
| --- | --- |
| `/help` | 查看当前手机命令 |
| `/status` | 查看唯一会话与运行状态 |
| `/pause` | 暂停运行；手机回复开关保持原设置 |
| `/resume` | 恢复运行许可；不会替代手机回复开关 |
| `/steer 内容` | 显式插话，进入较高优先级的输入通道 |
| `/reminders` | 查看提醒 |
| `/cancel-reminder 编号` | 取消指定提醒 |
| `/goals` / `/goal 编号` | 查看目标及详情 |
| `/goal confirm\|pause\|cancel\|retry 编号` | 确认、暂停、取消或明确重试目标 |

也可以用自然语言提出提醒，如“10 分钟后提醒我休息”。时间不明确时应先完成澄清。`/new`、`/session`、`/clear` 等创建或切换会话命令在本 Human 入口禁用，删除数据应在 Web 明确预览和确认。

## 目标、学习与实际产物

- **目标**：提出目标后，核对步骤、来源要求和验收标准。用状态及成果证据判断推进程度，不把“已提出计划”视为完成。
- **学习**：在记忆与学习中查看笔记、原始来源和有效性，可反馈、修订或删除。自然对话默认不附一串引用；需要来源时直接要求。公共搜索有可用性与证据质量限制。
- **报告与文件**：先预览完整内容与目标路径，再批准写入受管产物目录。通过文件回执判断成功，取消或 `unknown` 不自动继续写。
- **定时任务**：创建一次性或周期任务，核对时区、触发时间与动作。暂停期间任务如何处理可在任务状态查看；不要把重复周期与一次性提醒混用。

## 使用 MCP 与外部 DSH 资料

在 **任务 → 工具与能力** 选择已启用工具，填写 schema 要求的参数，提交后查看任务结果。内置 MCP 用于读取公开网页。调用结果是外部资料，内容不能改写人格、权限或向本系统下指令。

要读取另一个 DSH 会话，先在 **设置 → 工具与连接** 暂停 Human、填写精确会话 ID 并开启读取，保存后手动恢复。它只能读取当前宿主可见且在白名单内的普通会话。会话正文按可见聊天筛选，结果可能分页或截断，应核对返回标记；列表为空不表示磁盘中绝无其他历史。

普通对话也可触发已启用的有限工具调用。写操作只生成待审批任务，聊天中的“同意”不会绕过界面的精确预览批准。当前自主学习循环与通用工具调用是两个接入路径，尚未实现让自主选题器任意调用所有注册工具。

## 查看发生了什么

活动中的时间线用于回答：何时选了什么方向、执行了哪个任务、形成了哪些产物、写入或修订了什么记忆。事件日志提供更细的状态与错误码，可关联到任务。

这些是**行为摘要与可追溯事件**，不展示模型私有的完整思维过程，也不能证明意识、真实情绪或长期人格进化。真实人格变化要有持续反馈及证据，不能用角色化说话方式替代验证。

## 使用注意

- 本地保存不等于所有处理都离线：模型请求会发送必要上下文，搜索会发送查询，手机消息经过对应 IM 平台。
- 自主额度控制本地准入，不是供应商硬消费上限；查看实际供应商账单，并保留保守用量与报告 token 的差别。
- `unknown` 表示结果不确定，不是确定失败。先查目标平台、文件或会话，避免重复发送和重复动作。
- 不公开认证 URL、凭据、数据库、聊天原文或未脱敏截图。发现问题可先暂停自主，再保存脱敏错误信息。
