# Become Human 0.7.0-beta.45

这是 DSH Web 和 Windows Desktop 的测试版。授权一个 DSH 工作会话后，Human 可在自主选题时得知该来源有新消息，再决定是否阅读。主人询问进展时，草稿与回复复核使用同一批有效摘录。

## 使用变化

- 工作会话先说“导出缺签名”，后来确认“签名补齐、验收通过”，Human 可核对两条原话后放下旧阻塞。同一会话里尚待确认的其他工作仍保留。核对消耗自主额度，原始记忆和主人已管理的看板事项继续保留。
- 模型在选题外层和计划内同时写出相同的执行决定时可以继续。授权、机会编号和固定输入仍经过原有检查。
- 兼容适配器仅通过错误文字报告的 HTTP 502 空响应。工作观察保留阅读位置，对受影响的来源退避。

## 安装与验收

Web 可以安装 `dsh-become-human-web@0.7.0-beta.45`。Windows Desktop 可以在插件管理中安装同版主包。升级后请重启 DSH 宿主，再打开原 Human。[安装步骤](INSTALLATION.md) · [工作观察设置](WORK_OBSERVATION.md) · [测试记录](TESTING_STATUS.md)
