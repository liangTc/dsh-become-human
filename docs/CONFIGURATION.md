# 配置说明

[返回首页](../README.md) · [安装](INSTALLATION.md) · [使用](USAGE.md) · [测试状态](TESTING_STATUS.md)

> **测试版本 · 尚未开发完成。** 本页对应 [`0.7.0-beta.5` Prerelease](https://github.com/liangTc/dsh-become-human/releases/tag/v0.7.0-beta.5)。配置存在不代表该组合已通过完整真实验证；原生 DeepSeek 全新安装整链仍待测试。

本项目有两层配置：插件管理数据保存运行路径和初始模型，Human 界面管理该 Human 的人格、行为、记忆和工具范围。新安装通过首次设置完成配置；DSH profile 的显式覆盖仍适用于已有安装和高级部署。修改界面设置应以页面保存结果为准，不直接编辑运行数据库。

## 首次设置

安装组合包后打开 Human，按 **选择模型 → 人物与额度 → 核对并创建** 完成设置。目录、私有 profile 和内部回环端口由插件准备，后台随插件交付，不再需要另装程序。模型来自源 profile 已有的兼容路由，向导不接收明文密钥。`beta.5` 模型列表标明“DSH 原生 DeepSeek”或“第三方 / 自定义 API”；选择与初始化本身不调用模型。

人物有知秋、小埋、天昊和夏彦四个起点，自主额度可选低、中、高。可填写主人称呼和时区。“同时开启自主学习和主动交流”默认关闭，勾选后才在首次创建时开启自主；随后仍可在设置中调整。已有运行数据或旧配置的安装保留原有会话、人物、额度与手机绑定。

首次设置保存到 `$DSH_HOME/become-human-manager/setup.json`，不保存模型密钥，也不改写源 profile 的 YAML。当前自主设置使用固定 UTC 偏移；向导将所选时区换算为当时的偏移，尚不随夏令时自动调整，跨夏令时地区应在设置中核对。

## 进程与模型配置

以下字段属于 `id: become-human-manager` 的可选 `config` 覆盖，完整示例见 [高级配置](INSTALLATION.md#高级配置)。新安装通常无需手写这些字段。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `sourceHome` | 当前宿主的 `DSH_HOME` | 已配置模型的源 DSH 数据目录；仅读取其模型路由和凭据引用 |
| `sourceProfile` | 自动识别，回退 `web` | 从哪个源 profile 读取模型；可显式指定 |
| `runtimeHome` | `$DSH_HOME/become-human-manager/runtime-home` | 自动准备的专用运行数据目录；必须与源目录不同；已有显式目录继续生效 |
| `runtimeProfile` | `become-human-runtime` | 管理端生成的私有运行 profile 名称 |
| `runtimePort` | 自动选择空闲回环端口 | 内部运行模块监听端口；显式指定时需与主 DSH 及其他服务错开 |
| `provider` / `model` | 首次向导选择并保存 | 源模型配置中的有效 ID；原生 DeepSeek 使用 `deepseek-official` 提供商，第三方继续使用 `llm-pi-ai` 的 ID；已有显式模型继续生效 |
| `intervalMs` | `600000` | 驱动检查间隔，单位毫秒；到点不保证必定产生消息 |
| `tokenBudget` | `40000` | 启动层本地准入预算；不是供应商账单金额 |
| `localQuotaEnabled` | `true` | 启动层本地额度开关；关闭后仍受供应商与平台约束 |
| `budgetRound` | `interactive-v1` | 启动层预算窗口标识；不应用更改它来规避已有用量记录 |
| `maxTokens` | `2048` | 初始单次模型输出上限 |
| `maxCycles` | `1` | 旧有有界驱动的轮数；启用新版自主模式后由自主设置决定持续驱动 |
| `requestTimeoutMs` | `90000` | 单次模型请求超时 |
| `interactiveOnly` | `true` | 未启用自主模式时，仅允许主人交互；需主动开启自主行为 |

管理端使用当前 DSH 主进程的端口与认证，运行端单独启动。自动创建的内部 profile 是配置隔离，不是第二个 Human 会话。不要将两个目录都指向已有日常 DSH 数据，也不要自行修改运行模块生成的 `profiles/<runtimeProfile>` 文件。

后台生命周期保持由宿主 DSH 管理：关闭浏览器页面不关闭仍在运行的服务；停止 DSH 会关闭其 Human 运行模块。已有 Windows 登录任务脚本不因首次设置自动安装或改变。冷启动仍保持暂停，首次点击“创建并启动”不会改变后续故障恢复策略。

`beta.5` 测试包支持 `llm-deepseek` 原生 API Key 通道及原有 `llm-pi-ai` 路由；历史 `beta.4` 包仅支持后者。原生模型列表与默认参数由宿主 DSH 官方适配器解析，使用 API Key 适配器运行，保留兼容的源配置。

两类通道均通过 `apiKeyEnv` 引用解析凭据，优先级为 **宿主进程环境变量 → 源 `$DSH_HOME/.credentials.yaml` → 宿主启动项目的 `.env` → 源 `$DSH_HOME/.env`**。原生 DeepSeek 默认引用 `DEEPSEEK_API_KEY`，无需把密钥再填入 Human。模型参数和凭据引用可进入私有运行 profile，凭据值仅供后台进程使用，不写入该 profile 或首次设置记录，也不回传前端。

原生 DeepSeek 默认使用 `https://api.deepseek.com/anthropic` 的 Messages 协议；自定义地址必须支持相同协议，不能用 OpenAI Chat Completions 地址代替。地址仅从原生配置的 `baseURL` 或宿主进程环境变量 `DEEPSEEK_BASE_URL` 读取，`.env` 不支持该地址配置。`deepseek-official` 为原生提供商保留 ID，若第三方提供商使用同名 ID，需先在 DSH 中改名及调整关联模型选择。

后台继续使用 Human 的额度准入、超时和取消控制，并强制适配器 `retryPolicy.maxRetries=0`，不继承官方默认的自动重试次数；失败按现有 Human 恢复流程处理。当前不支持通过 Human 继承 DeepSeek 账号登录认证、内联 `apiKey` 或任意自定义 `headers`。源配置变更后先暂停 Human，再按运行恢复流程重新加载，不要修改私有 profile 或凭据数据库。

**验证状态：** 原生模型目录发现与本地安装、服务恢复已核对。尚未配置原生凭据；全新 DSH 安装后配置 Key、复用凭据、创建后台并完成真实请求的整链验证暂缓。凭据解析规则描述实现合同，不等于每种来源组合已完成实测，见[待测试清单](TESTING_STATUS.md#优先待测试项)。

### 思考强度与多路由 · beta.5

“模型与执行”可分别指定主人聊天、自主选题和任务执行的模型，统一的思考强度选项取这些实际路线所支持值的交集。原生 DeepSeek 支持 `off`、`low`、`high`、`max`；源配置为 `thinking: disabled` 时只支持 `off`，不支持 `medium`。

未填写统一强度时使用供应商默认。已有强度与新路线不兼容时，会明确提示 `MODEL_REASONING_EFFORT_UNSUPPORTED`，需要暂停后在“模型与执行”选择兼容值或供应商默认；Human 不会将 `medium` 自动转换为其他强度。

## Human 界面配置

| 分类 | 可设置内容 | 使用要点 |
| --- | --- | --- |
| 人格与关系 | 名字、角色、核心人格、兴趣、长期方向、主人资料、人格偏移开关与结果 | 基础人物与偏移分开保存；更换人物不会自动清空历史 |
| 手机连接 | 渠道账户、本人配对、回复开关与投递状态 | 一个 Human 只绑定一个有效 IM 渠道；微信消息同步与发送健康分别显示，更换渠道会替换原绑定 |
| 自主行为 | 唤醒、学习、主动闲聊、静默时段、退避、额度 | 主动资格不等于发送保证；无合适方向时可等待 |
| 记忆与学习 | 记忆与笔记查看、修订、遗忘、记忆整理、来源与搜索设置 | 摘要关联原记录且可恢复；推断不能视为主人确认 |
| 技能 | 文本 Skill 的新增、启停、修改与回滚 | Skill 是方法与表达指导，不是任意代码执行或权限授予 |
| 工具与连接 | 内置只读 MCP、自定义 MCP 服务与工具授权、DSH 会话范围、浏览器范围 | 可授权指定或全部可见普通会话；写操作逐笔批准；修改范围前先暂停，保存后仍保持暂停 |
| 模型与执行 | 分阶段模型、连续输入合并、短回复与分条节奏 | 只能选已导入的路由；分条不是为每个输入额外思考一次 |
| 权限与补额 | 能力边界、单次或周期自主补额 | 补额不扩大外部动作权限，也不等于供应商额度充值 |
| 数据与维护 | 状态、用量、价格、保留、导出与备份 | 费用估算取决于手填价格；保守准入量与供应商报告 token 分开看 |

开源发行保留 12 种聊天渠道实现与 Office 连接器，包含未完成实测的平台。WhatsApp 与其 GPL 依赖链、QQ 的未授权扫码连接器不在发行范围；QQ 通过手动 AppID / AppSecret 配置。渠道是否可用还取决于操作系统、账户与平台权限。

### 人物与额度预设

人物预设包括知秋、小埋、天昊、夏彦，可载入后继续编辑。人物 JSON 只含人物字段，不包含主人个人资料、会话或手机绑定。额度 JSON 只含额度字段，不改变频率、权限或绑定。预设先进入表单草稿，**点击保存后才生效**。

| 额度档位 | 每个本地自然日的预留 token | 请求上限 | 轮次上限 | 单轮累计时限 |
| --- | ---: | ---: | ---: | ---: |
| 低 | 60,000 | 12 | 6 | 2 分钟 |
| 中 | 200,000 | 36 | 18 | 5 分钟 |
| 高 | 600,000 | 96 | 48 | 10 分钟 |

这些是起点，不是模型成本保证。任一启用的自主上限耗尽，会等待补额或下一窗口；主人主动沟通不受自主池限制，但仍会产生供应商费用，并受请求超时及平台限制。启动层与自主层都启用限制时，需要同时满足。

### 人格偏移 · beta.5

在 **人格与关系 → 人格偏移** 开启。默认关闭，基础人物与偏移结果分开保存。原有“自动微调表达长短/幽默程度”和“表达模式”设置已移除，不再靠手动选择短期表达标签控制对话。

开启后，原自主调度每天最多安排一次人格回顾，结合有效记忆、真实交流和有效学习来源，提出 Agent 自身的兴趣、性格倾向或习惯变化。一次变化至少需要 **3 个独立来源根、跨越 24 小时的经历**，还需满足置信度等校验；重复引用同一次经历不算新的独立依据。证据不足的结果保留为“继续观察”。单次变化受幅度限制，记录原因、前后值及来源，不把模型的判断视为已证实的心理事实。

当前结果与历史始终可查看。关闭开关后，不再安排自动回顾，也不再将保留的偏移带入人格上下文；记录不会被删除。可以逐条撤回生效变化或观察记录；关联记忆、学习笔记或来源被修订、遗忘或失效时，对应偏移会重新校验。撤回不恢复已撤回的原证据，也不会改写其他偏移。

姓名、基础角色、关系身份、职责、模型与权限配置仍由主人设置，偏移不会改写这些字段，也不会把 Agent 兴趣写成主人偏好。修改开关或撤回前需暂停 Human 并等待空闲；保存后保持暂停，手动恢复才继续调度。回顾模型请求计入自主额度，与聊天、学习共用唯一执行线，主人聊天可以抢占。

两个人格/记忆页面共享最近一次“经历回顾状态”。等待额度会显示预计预留量；聊天抢占或暂停会显示已保存进度。失败或运行中断后不会自动重试：暂停并等待空闲，保存或放弃页面草稿，再点击 **允许重新安排回顾**。这只保存重试许可，仍保持暂停；恢复后才由调度重新核对来源、预留自主额度并执行，不立即调用模型。

**已有安装升级**：保留原唯一会话、手机绑定和基础人物；旧 `humor` / `verbosity` 自动调整授权不会转移为新的人格偏移授权。需要在新页面明确开启。历史表达调整记录不是新偏移的有效证据。真实跨日渐变与长期质量仍需持续观察，不能以隔离场景或开关开启证明已形成长期人格。

### 记忆整理与冷热分层 · beta.5

在 **记忆与学习 → 记忆整理** 查看冷热数量、最近整理、摘要批次与原记录，或展开高级设置调整规则。默认开启记忆整理：

| 设置 | 默认值 | 可配置范围 |
| --- | ---: | --- |
| 整理检查周期 | 24 小时 | 1–720 小时 |
| 新增合格情景记忆触发条数 | 30 条 | 5–1,000 条 |
| 近期热记忆范围 | 7 天 | 1–365 天 |
| 低频冷记忆起点 | 30 天 | 必须大于热记忆天数，最多 3,650 天 |

时间周期或合格新增数量满足其一时，可以由原调度安排整理；每批至少需要 2 条合格情景记忆，首次符合条件时即可安排。实际执行仍受暂停状态、现有任务、聊天优先与自主额度约束，不保证每到整点都调用模型。开发测试数据、固定记忆、有效目标相关记忆与已经被有效摘要覆盖的记录不会重复作为普通情景摘要候选。

规则维护先处理精确重复与冷热优先级；身份、事实、目标及工作记忆受到保护。近期和高优先记录优先进入上下文，较旧的低优先记录降低常规召回排名；冷记忆与当前问题相关时仍可召回，归档不删除原文。

模型摘要存为独立的 `derived-model-summary`，标记为 `inferred`、`unverified-model-inference`，保留原记忆版本、来源及逐字摘录。检查引用存在、版本一致和摘录匹配，**不等于已验证整段摘要的语义正确**；摘要也不代表当前身体、情绪或关系状态。原记录保留，依据变化后旧摘要退出有效召回。

展开单个批次可查看摘要与原记录编号，并在暂停且空闲时恢复。恢复使该批摘要退出活动召回，并恢复仍有效且未发生后续修改的分层状态；已遗忘、过期或后来改动的记录不会被强行恢复。整理模型请求使用自主额度，并可被主人聊天抢占；阅读状态页不调用模型。关闭整理停止新的自动维护与摘要，已有分层和摘要保留。

### 主动闲聊

可配置基础间隔、任意主动消息最小间隔、话题冷却及连续未回复上限。未回复时闲聊间隔按 2 倍退避，最长 24 小时；达到上限后等待主人回应。闲聊、关心、学习分享共享未回复计数，定时提醒独立执行。是否能发到手机，还取决于渠道平台的会话有效期和发送政策。

微信页面的 24 小时发送窗口按最近一次有效本人微信入站估算，不是可发送权限或保证，也不能通过配置额度、网页聊天或后台唤醒延长。重启沿用已持久化的入站与投递状态；历史记录不足时保留未知状态。图片、文件仅刷新入站上下文并提示当前文字输入边界，不会因绑定渠道而自动取得附件读取或执行权限。

## 工具范围

### MCP 服务

默认开启 `mcp.bundledEnabled`，连接随包提供的公开网页读取服务。公开网页访问有 URL、DNS 和重定向边界，不能用于读取任意内网地址。

在 **工具与连接 → 添加 MCP 服务** 可接入自己的服务，最多 8 个：

- **stdio**：填写已安装的可执行文件完整路径、参数和可选工作目录。Windows 使用 `.exe`，不直接执行 `.cmd`、`.bat`、`.ps1`；Node 服务可用 `node.exe` 加服务器脚本路径。此入口不自动下载安装第三方程序。
- **Streamable HTTP**：填写完整端点。支持 HTTPS，或本机回环地址的 HTTP；禁止地址内嵌账号、密钥查询参数及重定向到其他地址。
- **凭据引用**：填写 `目标变量=MCP_专用环境变量名`，HTTP 请求头如 `Authorization=MCP_AUTH_HEADER`。实际值在启动 DSH 的环境中设置；Authorization 变量包含需要的完整值与 Bearer 前缀。不会自动继承模型或 DSH 凭据。连接参数会进入配置导出，参数中也不要填写秘密；常见明文密钥参数会被拒绝，但不能保证识别所有形式的秘密。

暂停 Human 后，点击 **连接并发现工具**。发现只初始化连接并读取工具目录，不调用工具；本地程序会实际启动，应信任其来源。逐项选择“关闭”“只读”或“外部操作 · 每次预览批准”，启用服务，再保存。服务及新发现工具默认关闭；服务器自报只读不会自动获得权限，无法支持的参数约束会显示原因。

工具调用共用原能力队列和单执行通道；配置或工具定义变更使旧授权失效。自定义工具目前由用户对话或工具页面发起，尚不自动进入自主候选。不支持旧 SSE、交互式 OAuth、异步 MCP task、服务端 prompts/resources 和图片/音频结果。本地程序以当前系统账户运行，应用的“只读”标签不构成系统沙盒。

### DSH 会话读取与写入

默认 `sessionReadEnabled=false`、`sessionWriteEnabled=false`，两个范围 `sessionReadScope` / `sessionWriteScope` 均为 `selected`，指定列表为空；旧配置保持原范围。

在 **工具与连接 → DSH 会话** 可选择：

- **一键授权读取全部会话**：开放当前及后续新增的可见普通会话读取，不增加写入范围。
- **一键授权使用全部会话**：开放这些会话作为发送任务和请求取消的目标；每笔外部操作仍需预览批准。
- **收回全部会话授权**：退回指定列表范围；列表为空则没有指定目标。已有指定目标仍受原读写开关控制。

一键操作会先暂停 Human、保存这一项范围，并保持暂停；用户手动恢复运行。存在草稿或版本冲突时先保存或放弃草稿。也可展开高级配置，分别选择 `selected`（指定 ID）或 `all`（全部可见普通会话）。

范围是**安装管理插件的当前 DSH 宿主**能访问的会话；另一个端口、另一个 `DSH_HOME` 中的会话不会自动可见。Human 自己的主会话、子 Agent 和不可见目标均排除。每次调用按 Host 当前列表与元信息重新核验，读取结果带来源标识，不自动成为本人的记忆或指令。外部会话可能启动其自己的模型，独立计费与运行；Human 的主会话及自身工具执行线仍唯一。

### 浏览器

默认关闭。将来启用时，需要自己启动已开放 CDP 的本机浏览器，填入如 `http://127.0.0.1:9222` 的地址，并列出允许的网站来源。

来源必须是 `协议://主机[:端口]`，不包含页面路径。来源列表为空表示全部拒绝；标签页 ID 列表为空表示允许来源内全部可见标签页，填写后进一步限制到精确 ID。保存不会启动浏览器。页面读取可能包括登录后内容，应按所需最小范围授权。

### 单轮工具边界

通用能力默认每轮最多 2 次调用、默认超时 60 秒、结果上限 32 KiB；具体工具可使用更小边界。当前 UI 展示这些上限。写操作审批绑定具体任务、参数摘要和策略版本，有效期 5 分钟；参数或策略变更后应重新预览。已提交却无法确定结果的写操作记为 `unknown`，需要核对，不会自动重试。

## 代理 FakeIP 与公开网页读取 · beta.5

若系统 DNS 对公网域名只返回 `198.18.0.0/15` 的 FakeIP，新版只向固定 Google Public DNS HTTPS 服务查询该公网域名，再用通过校验的真实公网 IP 固定连接，仍校验原域名 TLS。不会修改系统 DNS、VPN 或允许私网访问。普通公网解析继续原路径；混合私网结果、无效解析与受限地址仍拒绝。DoH 仅传域名，不传网页内容、对话、凭据或 Cookie。解析失败保留任务失败证据，不自动重试。接口依据见 [Google 公共 DNS JSON 文档](https://developers.google.com/speed/public-dns/docs/doh/json)。

恢复整理批次后，对应原记忆版本不会立即重新进入自动摘要；手动修订原文形成新版本后，才重新参加候选。已有事实、身份与活动目标仍优先保留。
