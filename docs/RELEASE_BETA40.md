# Become Human 0.7.0-beta.40

测试发行（Prerelease），尚未开发完成。支持 Windows、Node.js 24+、DSH 0.2.0-rc.2 的 web profile。首次安装和长期可靠性仍按待测清单验收。

## 安装与升级

备份后停止需要更新的 DSH，保留原数据目录，然后安装固定版本：

```powershell
npx @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile web add dsh-become-human-web@0.7.0-beta.40 --registry=https://registry.npmjs.org/
npx @deepseek-ai/dsh@0.2.0-rc.2 web --no-open
```

也可下载本 Release 的组合包 `.tgz` 与 `.sha256`，校验后用相同 DSH 命令安装本地文件。组合包包含管理端和独立运行模块，不需单独安装内部 runtime。GitHub 自动生成的源码 ZIP 不可直接作为插件包安装。

## 相对 beta.39 的变化

- 独立的 **插件中心**：左侧选插件，右侧加载插件注册的设置和内容页面。移除设置、资料中的重复学习入口。
- `humanPlugins` v1：统一注册事件、行为、能力、来源、页面与托管定时，支持输入、选题、结果、反馈、记忆、成长、回复发布等生命周期回调。继续共用 Human 的唯一执行线、预算和权限。
- 可选学习包 0.2.0：自有 React 设置与笔记页面，保留旧笔记、批注与任务；按数据库分页读取。未新增新闻插件。
- 管理页面改为可读任务详情与会话记录；模型请求、返回按需读取，内部编号和原始 JSON 留在日志导出中，长详情保留固定关闭入口。
- 新增官方 npm 通道的一键更新、版本校验及失败恢复；仍需按提示重启宿主。首次新机器在线更新不等于已经验收。
- 微信管理请求诊断与恢复改进，避免重启期间误报、重复重连与遗留轮询；连接恢复不延长微信互动窗口，unknown 投递不自动重发。
- 模型异常和空输出提供更明确的诊断；自主预算通知与高档预设、透明 PNG 头像与未读提示等近期改进一并交付。供应商模型不可用仍需用户更换或修复，软件不能保证调用成功。

## 可选插件附件

- `dsh-human-learning-0.2.0.tgz`：需要 beta.40 的生命周期接口。已有 0.1.0 可通过插件中心安装此包升级，保留原笔记。启用页面不等于开启自主学习，两个开关分别管理。
- `dsh-human-experience-0.1.0.tgz`：经历回顾参考包，版本未变。

两个可选包只作为 Release 附件提供，本轮不单独发布到 npm。它们不自动安装，扩展属于可信本机代码，不是恶意代码沙箱。旧扩展的独立注册方式继续兼容，但任意第三方扩展尚未全面验收。
