# Human 经历回顾行为包

测试版本，需要 Become Human beta.24 或更新的兼容版本。基于有效的数字经历，让选择模型决定是否提炼暂定认识、调整方法或承担有期限的角色。不是自动人格改写，也不会发送消息或新建会话。

在此目录运行 `npm pack --ignore-scripts`，将生成的 `.tgz` 绝对路径填入 **Human → 设置 → 更多设置 → 工具与技能 → 行为扩展** 并安装。本包不依赖其他 npm 包；经历存储、校验、模型调用和权限由 Human 提供。

- 未安装：使用随 Human 提供的同版兼容实现。
- 安装：由独立包接管 `reflect-experience`，不会同时注册两份。
- 停用：该行为暂停，未完成任务保留检查点；其他行为和聊天继续可用。
- 再启用：相同定义继续使用原任务及幂等编号；变更定义不会静默执行旧计划。
- 卸载：恢复 Human 随附实现，保留历史经历、反思、任务与记忆。若只想停止回顾，请使用“停用”。

只读有效经历并提交可撤回的解释；原始证据仍由核心校验。开发测试、失效来源和反思自身不能成为新的独立成长证据。选择模型的费用计入原自主预算，执行提交不另开模型、调度器或数据库。本包需要可信代码权限，不构成沙箱；安装/配置会重启后台。

`humanExperience` v1 提供当前唯一主会话的 `recent({limit})`、`hasReflection(id)` 和 `reflect(input)`。包定义和输入 schema 保持原版本1及指纹，以兼容已有任务。此包只拆出经历回顾行为；学习、聊天、报告和经历数据库尚未全部拆成独立包。
