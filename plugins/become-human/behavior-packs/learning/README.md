# 探索与学习（可选行为包 · 测试版）

0.2.1 需要提供 `humanPlugins` v1 的Human beta.40 或后续兼容版本（beta.39 不包含本合同）。通过 Human 顶部 **插件 → 安装与管理** 安装本包的 `.tgz`。安装后默认停用；启用后在右侧 **学习设置 / 学习笔记** 中管理。只有打开自主学习并选择探索方式，才会产生学习机会。开启自主交流不会自动启用学习。

本包负责学习机会和选中后的读取、分析顺序，不拥有独立会话、定时器或模型通道。核心继续校验来源、调用额度和结果，保存笔记；学习不自动发送长篇内容。

配套的学习适配器根据来源、纠正反馈和已有笔记决定哪些任务可以继续。用户跳过话题时，相应学习路线降低优先级。证据不足会记录在原任务上。报告、闲聊等其他任务可以在学习任务等待时继续推进。

仅关闭自主学习时，主人仍可在聊天中要求查看笔记。停用或移除整个学习包时，Human 会撤下笔记查询、阅读和报告写入工具，进行中的回复也会在再次请求模型前检查资料是否仍可用。旧笔记、人工批注和任务检查点保留；主人可以显式导出历史资料或删除笔记。重新启用相同协议后，已有笔记恢复可读，等待中的学习步骤可继续推进。原有失败任务需手动重试。

本包使用 `humanPlugins.register` 统一注册工作流、React 页面和结果/反馈回调；停用统一清理。`humanLearning` v1 保留为旧 `research` / `learn-ai` 检查点及已有设置、笔记的迁移适配器。新增通用行为请注册 `behaviors`。扩展是受信任的本机代码，不是安全沙箱。包内不得自行启动额外模型循环或修改核心权限。

页面按需分页读取笔记，写入批注、反馈或学习设置需精确确认；Human 正忙时提示稍后操作，不抢断聊天。未保存的表单切换前会提示。旧笔记继续保存在原数据库中，不移动或复制为第二份记忆。
