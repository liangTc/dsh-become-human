# 探索与学习（可选行为包 · 测试版）

需要 Human 0.7.0-beta.25 或后续兼容版本。通过 Human 设置 → 工具与技能 → 行为扩展安装本包的 `.tgz`。安装后默认停用；启用扩展，再到学习设置选择探索方式，才会产生自主学习机会。开启自主交流不会自动启用学习。

本包负责学习机会和选中后的读取、分析顺序，不拥有独立会话、定时器或模型通道。核心继续校验来源、调用额度和结果，保存笔记；学习不自动发送长篇内容。

停用或移除后不会产生、执行或主动分享学习任务，也不会回退到隐藏内置版本。旧笔记、人工批注和任务检查点保留，聊天仍可按需查阅已有笔记；重新启用相同协议后可续接旧任务，旧失败任务不会自动重试。目标中的学习步骤会等待，不会被虚假标记为完成。公开读取、MCP 和其他已授权工具不依赖本包。

`humanLearning` v1 是旧 `research` / `learn-ai` 检查点的迁移接口，只接受版本1；新增通用行为请使用 `humanBehaviors`。扩展是受信任的本机代码，不是安全沙箱。包内不得自行启动额外模型循环或修改核心权限。
